# AI-Powered Sales Intelligence Platform

An internal business intelligence platform that automates monthly sales data ingestion, analytics, forecasting, and reporting.

## Features

- Monthly data upload
- Product Intelligence
- Customer Intelligence
- Regional Intelligence
- Pricing Analysis
- Time-Series Analysis
- Machine Learning
- Interactive Streamlit Dashboard

## Tech Stack

- Python
- SQLite
- SQLAlchemy
- Pandas
- Plotly
- Streamlit
- Scikit-learn
- Prophet
